# Лабораторная работа №3 — Работа с Big Data

## Демонстрация: https://drive.google.com/drive/folders/1-72ke8lE2BFdXNjwXfGMLkEpNVi57Vhn

В рамках лабораторной работы разработано веб-приложение рекомендательной системы для анализа данных электронной коммерции. Приложение позволяет загружать большой набор данных, обрабатывать его с помощью Apache Spark, обучать модели машинного обучения и просматривать результаты через веб-интерфейс.

## Выполнение требований лабораторной работы

### 1. Веб-интерфейс

Для взаимодействия с системой реализован веб-интерфейс на Flask.

Через него пользователь может:

- загрузить набор данных
- проверить корректность загруженных файлов
- запустить обработку данных
- запустить обучение моделей
- просмотреть статистику по набору данных
- получить персональные рекомендации
- посмотреть прогноз повторных покупок
- просмотреть визуализации результатов

### 2. Загрузка больших данных

Для демонстрации работы используется датасет **Instacart Market Basket Analysis**.

Набор данных содержит:

- 3 421 083 заказа
- 206 209 пользователей
- 49 688 товаров
- более 32 млн записей о товарах в заказах

Обработка большого объёма данных выполняется с помощью **Apache Spark / PySpark**.

Через веб-интерфейс загружаются следующие файлы:

```text
aisles.csv
departments.csv
order_products__prior.csv
order_products__train.csv
orders.csv
products.csv
```

Сами CSV-файлы в GitHub-репозиторий не добавлены из-за их большого размера.

### 3. Обучение моделей

После загрузки и проверки данных пользователь может запустить обработку данных и обучение моделей.

В приложении используются две модели машинного обучения.

#### ALS

Модель **ALS (Alternating Least Squares)** используется для построения персональных рекомендаций товаров на основе истории покупок пользователей.

Основные параметры:

```text
rank = 20
regParam = 0.1
alpha = 10
maxIter = 5
```

После обучения система может сформировать Top-N рекомендаций для выбранного пользователя.

#### Random Forest

Модель **Random Forest** используется для прогнозирования повторной покупки товара.

Для обучения используются характеристики истории покупок пользователя и товара, например:

- количество покупок товара
- номер первого заказа с товаром
- номер последнего заказа с товаром
- средняя позиция товара в корзине
- количество заказов пользователя
- частота покупки товара
- количество заказов с момента последней покупки

В результате модель определяет вероятность того, что пользователь снова приобретёт товар.

### 4. Визуализация данных

После обработки данных результаты отображаются непосредственно в веб-интерфейсе.

В приложении реализована визуализация:

- общей статистики датасета
- наиболее популярных товаров
- распределения заказов по времени суток
- распределения заказов по дням недели
- результатов обучения моделей
- персональных рекомендаций
- прогнозов повторных покупок

Для построения графиков используется **Chart.js**.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/meevaNastya/lab3.git
cd lab3
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
```

Активировать его на macOS/Linux:

```bash
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Основные Python-зависимости проекта:

```text
Flask
PySpark
NumPy
```

### 4. Проверить Java

Для работы Apache Spark требуется установленная Java.

Проверка:

```bash
java -version
```

Проект разрабатывался с использованием **OpenJDK 17**.

### 5. Запустить приложение

```bash
python app.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:5000
```
